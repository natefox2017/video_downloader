Bug 反馈

  1. 先在 chrome://extensions/ 重新加载插件并刷新问题网页。
  2. 再次复现问题，记录网站、视频标题和具体表现。
  3. 如果有报错，把页面控制台或扩展 Service Worker 控制台的错误一起附上。
  4. 到 GitHub Issues 提交问题；涉及登录/私密页面时不要粘贴 Cookie、Token 或带敏感参数的地址。
