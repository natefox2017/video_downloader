Video Download Helper

Detect and download videos from YouTube, TikTok, Douyin, Bilibili and more — right from your browser. Free and open source.

⬇ Download GitHub
Manifest V3 MIT License No build step

Features

Everything you need to save videos, nothing you don't.

🎯

Smart detection

Automatically detects videos as you play them. The extension icon shows a live count badge.

⚡

Batch downloads

Select multiple videos and download them concurrently with adaptive thread control.

👁

Video preview

Hover any card and hit play to preview before downloading.

🔗

Copy direct link

One click copies the direct video URL to your clipboard.

🧩

m3u8 merging

HLS segments are downloaded in parallel and merged into a single file automatically.

🔊

Separate audio tracks

Detects DASH video-only streams (e.g. Bilibili) and grabs the audio track too.

Supported platforms

Dedicated extractors for popular sites, generic sniffing for everything else.

YouTube TikTok Douyin Kuaishou Bilibili Weibo Xiaohongshu Xigua + any other site

Installation

Three steps, no build required.

Download the latest release ZIP from GitHub Releases and unzip it.

Open chrome://extensions/ and enable Developer mode (top right).

Click Load unpacked and select the unzipped folder. Done!
